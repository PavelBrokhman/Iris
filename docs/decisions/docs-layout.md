# Where things are written

Decided 2026-10-24 (Pavel: "berjom raskladku Milo"), done the same day (`IRIS-4`).

| What | Where |
|---|---|
| tasks, the plan of a piece, its check | Jira ([jira.md](jira.md)) |
| what is built, checked, where the work is | `docs/STATUS.md` - written when a branch lands |
| a decision, with its reason and date | `docs/decisions/`, a file per decision |
| alternatives, accumulated, not overwritten | `docs/design/` |
| how it is built | `docs/architecture/` |
| how to install and to check | `docs/guides/` |
| what is closed | `docs/archive/` |
| what is known about video | `docs/knowledge.md` |
| the rules of working with Claude | Claude's memory and `CLAUDE.md` |

A folder is made when it gets its first file: `design/` and `guides/` have none yet.
